# 실행 파일 쓰기 금지

**실행 파일에 대한 쓰기를 금지하세요.**

실행 파일로 사용 중인 파일에 쓰기를 금지하는 코드를 추가하세요. 디스크에서 수정 중인 코드를 프로세스가 실행하면 예측할 수 없는 결과가 생길 수 있어 많은 OS가 이 방식을 사용합니다. 프로젝트 3에서 가상 메모리를 구현하면 특히 중요해지지만 지금 적용해도 좋습니다.

`file_deny_write()`를 사용하면 열린 파일에 대한 쓰기를 막을 수 있습니다. 해당 파일에 `file_allow_write()`를 호출하면 다른 곳에서 여전히 쓰기를 금지하고 있지 않은 한 쓰기가 다시 허용됩니다. 파일을 닫아도 쓰기가 다시 허용됩니다. 따라서 프로세스가 실행되는 동안 실행 파일을 계속 열어 두어야 그 파일에 대한 쓰기를 막을 수 있습니다.
