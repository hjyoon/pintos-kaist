# 유저 메모리 접근

**유저 메모리 접근 기능을 구현하세요.**

시스템 콜을 구현하려면 유저 가상 주소 공간의 데이터를 읽고 쓰는 방법이 필요합니다. 인자 값을 가져오는 단계에서는 이 기능이 필요하지 않습니다. 하지만 시스템 콜 인자로 전달된 포인터가 가리키는 데이터를 읽을 때에는 이 기능을 거쳐야 합니다. 유저가 잘못된 포인터, 커널 메모리를 가리키는 포인터 또는 일부가 잘못된 영역에 걸친 메모리 블록을 전달할 수 있으므로 주의해야 합니다. 이런 경우에는 해당 유저 프로세스를 종료해야 합니다.
