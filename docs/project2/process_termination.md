# 프로세스 종료 메시지

**프로세스 종료 메시지를 출력하세요.**

유저 프로세스가 `exit` 호출이나 그 밖의 이유로 종료할 때마다 **프로세스 이름과 종료 코드를 출력하세요**. 형식은 다음 출력과 같아야 합니다.

```
printf ("%s: exit(%d)\n", ...);
```

출력하는 이름은 `fork()`에 전달된 전체 이름이어야 합니다. 유저 프로세스가 아닌 커널 스레드가 종료하거나 halt 시스템 콜이 호출될 때에는 이 메시지를 출력하지 마세요. 프로세스 로딩에 실패했을 때에는 메시지를 출력해도 되고 생략해도 됩니다.

이 메시지 외에는 제공된 Pintos가 원래 출력하지 않던 메시지를 출력하지 마세요. 디버깅 중에는 추가 출력이 유용할 수 있지만, 채점 스크립트를 혼동시켜 점수가 낮아질 수 있습니다.
