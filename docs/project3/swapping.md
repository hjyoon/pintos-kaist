# 스왑 인/아웃

메모리 교환은 물리적 메모리의 사용을 극대화하기 위한 메모리 복원 기술입니다. 메인 메모리의 프레임이 할당되면 시스템은 사용자 프로그램으로부터 더 이상의 메모리 할당 요청을 처리할 수 없습니다. 하나의 해결책은 현재 디스크에 사용되지 않는 메모리 프레임을 교환하는 것입니다. 이것은 일부 메모리 리소스를 해방시키고 다른 응용 프로그램에 사용할 수 있습니다.

교환은 운영 체제에서 이루어집니다. 시스템이 메모리가 끝났다는 것을 감지하지만 메모리 할당 요청을 받으면 ዲስ크를 교환하기 위해 배제하는 페이지를 선택합니다. 그 다음, 메모리 프레임의 정확한 상태가 디스크에 복사됩니다. 프로세스가 교환된 페이지에 접근하려고 할 때, OS는 정확한 내용을 메모리로 가져와서 페이지를 복구합니다.

퇴거을 위해 선택된 페이지는 익명 페이지 또는 파일 기반 페이지일 수 있습니다. 이 섹션에서, 당신은 각 사건을 처리 할 것입니다.

스왑 연산은 함수를 직접 지정해 호출하는 대신 함수 포인터를 통해 호출합니다. 이 포인터들은 `struct page_operations file_ops`의 멤버이며 각 페이지 초기화 과정에서 해당 페이지의 연산으로 등록됩니다.

## 익명 페이지

**`vm_anon_init` 및 `anon_initializer`을 `vm/anon.c`로 수정합니다.** 익명 페이지에는 백업 저장소가 없습니다. 익명 페이지의 교환을 지원하기 위해, 우리는 스와프 디스크라고 불리는 시간적 백업 스토리지를 제공합니다. 익명 페이지에 대한 swap를 구현하기 위해 swap 디스크를 사용할 것입니다.

------------------------------------------------------------------------

```
void vm_anon_init (void);
```

> 스왑 디스크를 설정합니다. 사용 중인 영역과 빈 영역을 관리할 자료 구조도 필요합니다. 스왑 영역은 PGSIZE(4096바이트) 단위로 관리합니다.

------------------------------------------------------------------------

```
bool anon_initializer (struct page *page, enum vm_type type, void *kva);
```

> 이것은 익명 페이지의 초기화입니다. 교환을 지원하기 위해 `anon_page`에 몇 가지 정보를 추가해야 합니다.

이제 `anon_swap_in` 및 `anon_swap_out`을 `vm/anon.c`에 구현하여 익명 페이지의 교환을 지원합니다. 페이지의 교환이 필요하기 때문에 `anon_swap_out`을 구현하기 전에 `anon_swap_in`을 구현하는 것이 좋습니다. 데이터 컨텐츠를 스위프 디스크로 이동시켜서 안전하게 메모리로 가져오셔야 합니다.

------------------------------------------------------------------------

```
static bool anon_swap_in (struct page *page, void *kva);
```

> 스위프 디스크에서 익명 페이지에서 스위프 디스크에서 메모리에 데이터 내용을 읽음으로써 swaps. 데이터의 위치는 페이지를 교환했을 때 페이지 구조에 저장되어 있어야 할 수 있습니다. 스왑 테이블을 업데이트하는 것을 기억하십시오 ([스왑 테이블 관리](introduction.md) 참조).

------------------------------------------------------------------------

```
static bool anon_swap_out (struct page *page);
```

> 메모리 내용을 스왑 디스크로 복사해 익명 페이지를 스왑 아웃합니다. 스왑 테이블에서 빈 슬롯을 찾아 페이지 데이터를 복사하고, 그 위치를 page 구조체에 저장합니다. 디스크에 빈 슬롯이 더 이상 없으면 커널 패닉을 발생시켜도 됩니다.

## 파일 매핑 페이지

파일 기반 페이지의 내용은 파일에서 나오는 것이기 때문에, mmaped 파일은 백업 저장소로 사용되어야 합니다. 즉, 파일 뒷받침된 페이지를 추방하면 그 파일이 매핑된 파일에 다시 기록됩니다. `file_backed_swap_in`, `file_backed_swap_out`을 `vm/file.c`에 구현한다. 디자인에 따라 `file_backed_init` 및 `file_initializer`을 수정할 수 있습니다.

------------------------------------------------------------------------

```
static bool file_backed_swap_in (struct page *page, void *kva);
```

> `kva`에 있는 페이지에서 파일에 있는 내용을 읽음으로써 swaps. 파일 시스템과 동기화해야 합니다.

------------------------------------------------------------------------

```
static bool file_backed_swap_out (struct page *page);
```

> 파일로 내용을 다시 작성함으로써 페이지를 교환합니다. 먼저 페이지가 더럽지 않은지 확인해 보세요. 더럽지 않은 경우 파일의 내용을 수정할 필요가 없습니다. 페이지를 교환한 후 페이지의 더러운 부분을 끄는 것을 기억하십시오.
