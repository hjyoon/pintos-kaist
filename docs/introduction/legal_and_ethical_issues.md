# 법적·윤리적 문제

원래 Pintos는 자유로운 사용·수정·배포를 허용하는 관대한 라이선스로 배포됩니다. Pintos를 개발하며 학생이나 다른 사람이 직접 작성한 코드는 작성자가 소유하며 어떤 목적으로든 사용할 수 있습니다. Pintos는 *어떠한 보증도 제공하지 않으며* *상품성*이나 *특정 목적에 대한 적합성*도 보증하지 않습니다. 라이선스와 보증 부인의 자세한 내용은 License 파일을 참고하세요. 하지만 pintos-kaist의 수정 코드는 같은 라이선스를 따르지 않습니다. *RECEX SHARED SOURCE LICENSE*를 사용하므로 이 코드를 바탕으로 한 작업은 *재배포해서는 안 됩니다*. 자세한 내용은 `LICENSE`를 참고하세요.

KAIST CS330 수업에서는 명예 규약의 취지와 문구를 존중해 온라인이나 다른 곳의 과제 해답을 읽지 마세요. Linux나 FreeBSD 같은 다른 OS 커널의 소스 코드를 읽는 것은 허용되지만 그 코드를 그대로 복사해서는 안 됩니다.
